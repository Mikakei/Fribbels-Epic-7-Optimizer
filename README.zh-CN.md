## 关于这个维护版本

这是 [fribbels/Fribbels-Epic-7-Optimizer](https://github.com/fribbels/Fribbels-Epic-7-Optimizer) 的自行维护版本。原项目已经很久没有更新了，所以我自己做了个维护版本，并修复了一些问题：

- 用当前源码重新编译后端，让社区贡献者后来加入的战意、追击、弱化、热忱套装能正常参与计算
- 恢复启动时联网更新英雄和神器数据；服务器上的数据过期时，自动改用 GitHub 上的数据
- 修复删除已穿戴的装备后，再删除、卸下或锁定该英雄时报错的问题
- 去掉赞助入口，"信息"页改为维护说明；增加检查更新、导入环境检测和加速器网络诊断工具

**下载：** 到 [Releases](https://github.com/Mikakei/Fribbels-Epic-7-Optimizer/releases) 下载 `FribbelsE7Optimizer-<版本>-win-x64.zip`，解压后运行 `FribbelsE7Optimizer.exe`。压缩包自带 Java，不需要另外安装。详见"[安装](#安装)"一节。

想从源码运行或参与维护，请看 [MAINTENANCE.md](MAINTENANCE.md)。

感谢原作者 Fribbels 创造了这个配装器，也感谢一直补充英雄和神器数据的社区贡献者。

## 配装器页

下面以一个坦克型的光之瑞儿配装为例，介绍配装器页的各个部分。这里有好几个用来筛选装备的面板，我会逐一详细说明。

_________________

### 设置面板

![](https://i.imgur.com/eIWkJ09.png)

这个面板保存其他面板要用到的设置。

- **英雄**：从下拉菜单里选择要配装的英雄。
  - **开始**：开始配装计算。
  - **过滤**：计算完成后，点击它按过滤面板里的属性筛选结果。
  - **取消**：中断并取消正在进行的计算。
  - **Load settings**：载入这个英雄上一次搜索时的配装设置。
  - **Reset settings**：把所有配装设置恢复为默认值。
- **属性**：左边是英雄当前的属性，右边是换上新装备后的属性。
- **选项**：调整配装时的选项。
  - **使用重铸后的属性**：在搜索中使用 +15、85 级装备重铸后的预测属性。
  - **使用副属变更**：在配装时考虑使用副属性转换石。要先在英雄页为每个英雄设置好相关选项，才能使用这个功能。
  - **仅显示满级装备**：勾选后，只使用已经 +15、不能再强化或重铸的装备。
  - **锁定的装备**：勾选后，锁定的装备也会参与计算；不勾选时，忽略锁定的装备。
  - **已装备的装备**：勾选后，其他英雄身上的装备也会参与计算；不勾选时忽略这些装备，但英雄自己身上的装备除外。
  - **保留现有装备**：勾选后，英雄会保留当前穿着的装备，配装器只为空着的部位寻找装备。
  - **排除已穿上的装备**：选择一些英雄，他们身上的装备不会被拿来配装。把已经配好的英雄加进来，其他英雄就不会抢走他们的装备。只在勾选了"已装备的装备"时有效。

### 属性过滤

![](https://i.imgur.com/9VPlYjo.png)

这个面板设置用来筛选配装结果的属性。左边的框是最小值，右边的框是最大值，都包含边界。在这个例子里，我们要找的配装是：
- 生命至少 20,000
- 防御至少 2,400
- 速度在 180 到 200 之间

点击提交后，这些条件会作用在配装结果上。结果出来以后，你还可以改这里的数字，再点"过滤"按钮进一步缩小范围，不需要重新搜索。

_________________

### 评分过滤

![](https://i.imgur.com/VvNA4ca.png)

这个面板和属性过滤类似，但针对的是计算出来的评分。这些数值在游戏里看不到，但能帮你在不同配装之间做选择。

- **HpS**：`生命 × 速度`。适合既要速度又要纯生命的角色。
- **Ehp**：有效生命，计算方式是 `生命 × (防御/300 + 1)`。衡量角色在倒下前能承受多少伤害，适合评估角色有多耐打。
- **EhpS**：`有效生命 × 速度`。适合既要速度、又要靠生命和防御来抗伤害的角色。
- **Dmg**：平均伤害，计算方式是 `攻击 × 暴击率 × 暴击伤害`。衡量角色平均能打出多少伤害。注意它把暴击率算在内，所以降低暴击率会拉低 Dmg 评分，因为暴击次数变少，平均输出也就变低了。
- **DmgS**：输出效率，计算方式是 `攻击 × 暴击率 × 暴击伤害 × 速度`。衡量角色打出伤害的速度。
- **Mcd**：最大暴击伤害，计算方式是 `攻击 × 暴击伤害`。和 Dmg 不同，它不考虑暴击率，假设角色有 100% 暴击率。适合只需要 50% 暴击率的角色（比如挑战者多米妮尔），或者打 PVE 时有属性克制、只需要 85% 暴击率的角色。
- **McdS**：最大输出效率，计算方式是 `攻击 × 暴击伤害 × 速度`。和 DmgS 类似，只是不算暴击率。
- **DmgH**：战士型评分，计算方式是 `生命 × 暴击伤害`。适合伤害随生命成长的战士型角色。
- **CP**：游戏里角色属性页显示的战斗力，但不计算技能强化。适合用剩余装备给闲置角色配装去打世界首领。

### 副属性优先级过滤

![](https://i.imgur.com/w55RbpG.png)

**这大概是最有用的过滤条件，但使用前请先读完这一节。用错的话，好的结果可能会被排除掉。**

给每种副属性设一个 -1 到 3 的优先级。配装器会检查每件装备，计算每种属性相当于多少次满值成长，再乘以你设的优先级。把一件装备所有属性的得分加起来，就是这件装备的副属性得分，然后按得分从高到低排序。

这个例子里，我们主要想要一个又快又耐打的光之瑞儿，所以这样设：
- 生命和防御设为最高的 3，因为它们最重要
- 速度稍低，设为 2
- 抵抗设为 1，有了更好，对她也有点用
- 攻击、暴击率、暴击伤害、效果命中都不太在乎，保持 0

然后把"前%"滑块拉到 30%。配装器会给你所有的武器按上面的优先级打分，只取得分前 30% 的武器参与配装；头盔、铠甲等其他部位也一样处理，然后只用这些前 30% 的装备来生成组合。

**"前%"滑块必须设成 100% 以外的值，这个过滤才会生效**，否则用的就是全部装备，什么也没过滤掉。要注意，这个评分只是一种估算，百分比设得太低时不一定能得到最优结果。我觉得 30% 到 50% 比较合适，50% 就能过滤掉大部分无关的装备，比如坦克配装里的输出属性装备，反过来也一样。低于 30% 时，过滤会变得很敏感，可能没有足够的装备来得出最优结果，有用的装备被过滤掉，结果里就会缺少一些组合。可以多试几个不同的"前%"值。

像执行官维德瑞（Arby）这样的输出角色只需要伤害属性，优先级可以这样设：

![](https://i.imgur.com/iy4A8d2.png)

又比如坦克型的终结者杰拉图，需要兼顾耐打、伤害和效果命中，但**不要**抵抗，就可以把抵抗设成 -1，带抵抗副属性的装备得分会降低：

![](https://i.imgur.com/idsnxVW.png)

设好优先级过滤会让配装轻松很多，因为不用再考虑无关的或者成长不好的装备。

### 配装结果

![](https://i.imgur.com/qxzV1HS.png)

这里显示配装计算的所有结果，可以按属性排序，也可以装备或锁定结果里的装备。
- 第一行是英雄当前穿着的装备的属性

## 装备页

![](https://i.imgur.com/hEjsPOJ.png)

这里是你所有装备的表格，可以排序和筛选。底部的图标用来按套装和部位筛选，X 用来清除筛选条件。

### 装备分数

**分数** 一列是我自己定义的指标，和 WSS 类似，区别是它把固定值属性也算进去，而 WSS 会忽略固定值。计算方式是：

    分数 = 攻击%
    + 防御%
    + 生命%
    + 效果命中
    + 效果抵抗
    + 速度 × (8/4)
    + 暴击伤害 × (8/7)
    + 暴击率 × (8/5)
    + 固定攻击 × 3.46 / 39
    + 固定防御 × 4.99 / 31
    + 固定生命 × 3.09 / 174

它衡量一件装备的成长有多好，以 85 级装备的最大成长值为基准（速度的最大值按 4 算，不是 5）。我找出固定值属性的平均成长值，和满级 5 星角色的平均基础属性做比较，用来衡量固定值成长得好不好。（例如固定防御的平均成长是 31，相当于普通角色 4.99% 的防御。）

这一页上的其他分数是：
* 输出分（dScore）：只计算攻击和攻击%、暴击率、暴击伤害、速度的分数
* 支援分（sScore）：只计算生命和生命%、防御和防御%、效果抵抗、速度的分数
* 综合分（cScore）：不计算效果命中和效果抵抗的分数


![](https://i.imgur.com/L3pbMp6.png)

点击 *装备/编辑装备* 按钮并填写相应的栏位，可以编辑已有的装备或添加新装备。

### 副属性变更选项

**增加副属偏好** 按钮用来设置这个英雄在开启副属变更时的配装选项。

![](https://i.imgur.com/wxUsDWI.png)

在副属性选择菜单里，可以把副属性从 *不要改变* 一列拖到 *Wanted*（想要）或 *Unwanted*（不想要）。不想要的副属性会被换成想要的副属性，*不要改变* 一列里的副属性不会被修改，也不会作为目标。

* **选项**
  * Limit rolls：最多替换几次成长。例如设为 1 时，只替换没有被强化过的初始副属性。一般不建议替换超过 2 次，数字越大，生成的组合越多。
  * Mod grade：使用高级还是低级转换石的数值。
  * Roll quality：变更后的副属性取什么数值，从最小成长值到最大成长值。游戏里实际得到的数值是随机的。数值会四舍五入到整数。
  * Wanted stats：想要的副属性能否被换成另一个想要的副属性。例如允许时，一个最小值的速度可以换成最大值的速度；不允许时，速度保持不变。
- **使用副属变更的技巧**
  - 每一种副属性变更都被当作一件新装备，所以需要调高"前%"，并等更久才能得到好结果
  - "想要"和"不想要"的副属性选得越少，计算越快，因为生成的组合更少
  - 开启副属变更后，搜索几十亿种组合很常见。锁定装备、使用英雄优先度等过滤条件可以缩小搜索范围
  - 配装器只是展示变更的可能性，为了某一套配装去变更某件装备不一定划算，请谨慎选择
  - 每一次副属性变更都算作一次升级，可以用"需强化"（Upg）过滤，例如只想变更 1 到 2 件装备时

### 安装

#### Windows

1. 到维护版的 [Releases](https://github.com/Mikakei/Fribbels-Epic-7-Optimizer/releases) 页面，下载最新版本里的 ``FribbelsE7Optimizer-<版本>-win-x64.zip``
    * 不要下载 Source code，那些用不了
2. 把压缩包解压到任意文件夹，例如 ``D:\FribbelsE7Optimizer``
3. 双击文件夹里的 ``FribbelsE7Optimizer.exe`` 启动
    * 压缩包自带 Java，不需要另外安装
    * 如果 Windows 提示"Windows 已保护你的电脑"，点"更多信息"，再点"仍要运行"。程序没有数字签名，所以会有这个提示
4. 想用自动导入的话，按下面的步骤设置

**更新：** 菜单"工具 → 检查更新"会检查有没有新版本。有的话，下载新的压缩包，用解压出来的新文件夹替换旧的即可。存档保存在"文档\FribbelsOptimizerSaves"里，不受影响。

#### macOS

> 维护版没有 macOS 版本，下面是原作者官方版本（最新 v1.10.0）的安装方法，它不包含[维护版的修复](#关于这个维护版本)。

1. 在 [Releases](https://github.com/fribbels/Fribbels-Epic-7-Optimizer/releases) 页面选择最新版本，下载类似 ``FribbelsE7Optimizer-x.x.x-mac.dmg`` 的文件
    * 不要下载 Source Code，那些用不了
2. 安装 **64 位 Java 8**
    * Mac 需要同时安装 JRE 和 JDK：
    * JRE：https://java.com/en/download/manual.jsp ，选 64 位离线安装包
    * JDK：https://www.oracle.com/java/technologies/javase/javase8u211-later-archive-downloads.html
    * 安装完必须重启电脑！
3. 按下面的步骤设置自动导入

### 设置自动导入

推荐使用自动导入，需要先完成以下步骤：

#### Windows 首次设置

可以跟着视频教程一步步做：https://youtu.be/bDjP5eiOfK0?t=182

1. 安装 [Python 3](https://www.python.org/downloads/)，选 Windows 64 位安装包。**重要：安装时勾选 "Add Python to PATH"**
2. 安装 [Npcap](https://npcap.com/#download)，需要管理员权限。用无线网卡上网的话，安装时勾选 "Support raw 802.11 traffic (and monitor mode) for wireless adapters"
3. 重启电脑
4. 打开配装器，在菜单"工具 → 检测导入环境"里确认每一项都是 √

#### Mac 首次设置

1. 安装 [Python 3.4 或更高版本](https://www.python.org/downloads/release/python-392/)。还需要额外设置，把 python3 设为默认版本，推荐用 pyenv（https://opensource.com/article/19/5/python-3-default-mac）
2. 安装 [Wireshark](https://www.wireshark.org/download.html)
3. 安装 Wireshark 时，也要安装 ChmodBPF.pkg：[示意图](https://i.imgur.com/FqV0BA5.png)
4. 重启电脑

### 使用自动导入

自动导入支持 Google Play Games 电脑版、任意模拟器、手机，以及 M1 及以后芯片的 Mac。

#### 在模拟器或电脑上导入

适用于 Google Play Games 电脑版、模拟器和 M1 及以后芯片的 Mac。

可以跟着视频教程一步步做：https://youtu.be/bDjP5eiOfK0?t=357

1. 按上面的说明安装需要的软件
2. 模拟器可以开着，但要关掉第七史诗
3. 点击 **开始扫描**
4. 打开第七史诗，进入大厅
5. 点击 **停止扫描**
6. 等最多 30 秒，数据出现后点击 **导出**，保存为 "gear.txt"
7. 用 **合并** 选项导入 "gear.txt"
8. 到装备页，用 等级 = 0 的筛选找出等级为 0 的装备，手动修正

#### 从手机导入

1. Windows 10 及以上：打开"移动热点"设置：[示意图](https://i.imgur.com/89o8NfG.png)
    * Mac：在系统偏好设置里打开"互联网共享"（视硬件而定，部分机型可能没有）
2. 用手机连接电脑开的热点（必须由电脑提供热点，手机去连接）
3. 按上一节"在模拟器或电脑上导入"的第 3 到 8 步操作，把模拟器换成手机

### 为角色配装

1. 在英雄页选择英雄名字，点击 **添加英雄**。
2. 选中新添加的英雄，点击 **更改英雄信息**，填入神器、刻印、专属装备带来的属性。[示例](https://i.imgur.com/2aC22mN.png)
3. 到配装器页选择这个英雄，在右侧面板填写想要的主属性和套装。[示例](https://i.imgur.com/3yfbkrE.png)
4. 填写需要的过滤条件。每个过滤条件的详细说明见"[配装器页](#配装器页)"一节。
5. 点击提交，稍等片刻就能看到结果表格。
6. 用方向键或鼠标浏览结果，选中想要的结果后点击 **Equip Selected**。
7. 现在英雄就穿上这套装备了。
8. 如果想手动给某个英雄装备某件装备，到装备页点击 *装备/编辑装备*，在"装备"一栏选择英雄。[示例](https://i.imgur.com/Bqs3ETL.png)

这个视频涵盖了大部分导入流程：https://www.youtube.com/watch?v=i_QW4INcZIE

### 获得好结果的技巧

下面是一些快速得到好结果的技巧，前提是你已经读过"[配装器页](#配装器页)"里各个面板的说明。

* **尽量填写套装和主属性。** 这是缩小结果范围最简单的方法。
* **使用副属性优先级过滤，并确认优先级设得正确！**
  * 比如输出角色应该优先攻击、暴击率、暴击伤害、速度。
  * 坦克角色应该优先生命、防御、速度。
  * 优先级设得不好，好的装备会被过滤掉，结果也会变差。
* **调低"前%"可以加快搜索，调高则能搜索更多结果。** 我大多数时候用 20% 到 30%，只想用最好的装备时会更低。
* 如果想让某件装备一直留在某个英雄身上，先到装备页点击 *装备/编辑装备*，在"装备"一栏把它装到这个英雄身上。[示例](https://i.imgur.com/oNO9ivL.png) 然后配装时勾选"保留现有装备"，就会保留这件装备。

## 常见问题

### 自动导入的问题
* 先在菜单"工具 → 检测导入环境"里检查，每一项都应该是 √，没通过的项会给出处理提示。
* 超过 30 秒还没有结果，也没有报错：
  * 确认已经安装了需要的软件（Windows 需要 Python 和 Npcap，Mac 需要 Python 和 Wireshark），或者尝试重新安装。
  * 重启电脑
* 开着加速器时抓不到数据：
  * 用菜单"工具 → 加速器网络诊断"查看游戏数据走了哪条路。它只在本机运行，不上传任何东西。
  * 加速器运行在模拟器里面（安卓加速器应用）时，数据在模拟器内部就被加密了，电脑上抓不到。可以改用电脑版加速器的"模拟器加速"，或者扫描的那几十秒暂停加速。
* 出现报错：
  * 多试几次，偶尔会失败
  * 如果开着 VPN，关掉它，或者把加密方式改成 UDP
  * 如果开启了 Hyper-V，有几种办法：
    * 换一台没有开 Hyper-V 的电脑导入
    * 打开"网络连接"，禁用 Hyper-V 的 BlueStacks 网卡，然后改用手机热点的导入方式
    * 或者修改扫描程序的代码，写死你的网卡：https://github.com/fribbels/Fribbels-Epic-7-Optimizer/issues/50#issuecomment-804275567

### 配装器的问题

- 遇到 Java 相关的问题：
  - 维护版的压缩包自带 Java（程序文件夹里的 ``jre``），一般不会遇到。如果遇到，确认压缩包完整解压了，``jre`` 文件夹还在。
  - 重启电脑后再打开程序（可能有旧的后台进程还在运行）。
  - 使用原作者的官方版本时，需要自己安装 64 位 Java 8，并确认 Java 在 PATH 环境变量里：https://mkyong.com/java/how-to-set-java_home-on-windows-10/

- 下载后无法运行程序：
  - 你可能下载的是 Source code。到 https://github.com/Mikakei/Fribbels-Epic-7-Optimizer/releases 下载 ``FribbelsE7Optimizer-<版本>-win-x64.zip``，不要下载 Source code。
  - 不要直接在压缩包里运行，先完整解压到一个文件夹。
  - Windows 提示"Windows 已保护你的电脑"时，点"更多信息"，再点"仍要运行"。

- 导入时弹出 "Error: EPERM: operation not permitted"，有几种可能的解决办法：
  - 重启电脑，特别是最近刚装过 Java 的话
  - 杀毒软件可能拦截了程序，试着关掉它。我见过 Avast 导致的问题，暂时关掉 Avast 就好了。
  - 文件或文件夹的内容可能被压缩了，在文件夹属性里取消这个选项：https://i.imgur.com/kSzTqek.png
  - 以管理员身份运行程序
  - 把程序文件夹移到别的位置
  - 关闭 Windows 安全中心的勒索软件防护（受控文件夹访问）：https://www.majorgeeks.com/content/page/how_to_enable_or_disable_windows_defender_exploit_guard_controlled_folder_access.html

- 在 Mac 上提示 "The application "FribbelsE7Optimizer" can't be opened"：
  - 右键点击程序，在菜单里选"打开"
  - 改用 App Store 里的 The Unarchiver 解压，不要用系统自带的归档实用工具。[示例](https://i.imgur.com/y9uGQcH.png)

- 结果里有很多行属性完全相同，说明你可能有重复的装备。[示例](https://i.imgur.com/hUcyN1I.png)
  - 用装备页的"复制"（Duplicates）筛选找出并处理重复的装备，或者用覆盖、合并的方式重新导入装备数据。使用追加（Append）要小心，可能会加入重复的装备。大多数时候应该用合并。
