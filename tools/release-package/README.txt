Fribbels 第七史诗配装器 · 维护版
================================

这是 Fribbels Epic 7 Optimizer 的自行维护版本。原项目已经很久没有更新了，这个版本修复了一些问题。
原项目：https://github.com/fribbels/Fribbels-Epic-7-Optimizer
维护版：https://github.com/Mikakei/Fribbels-Epic-7-Optimizer

开始使用
--------
1. 把压缩包解压到任意文件夹，例如 D:\FribbelsE7Optimizer。
2. 双击 FribbelsE7Optimizer.exe 启动。
3. 已经自带 Java，不需要另外安装。

如果 Windows 提示"Windows 已保护你的电脑"，点"更多信息"，再点"仍要运行"。这个程序没有数字签名，所以会出现这个提示。

自动导入装备
------------
自动导入需要另外安装两个软件：
- Python 3：安装时勾选 "Add Python to PATH"。https://www.python.org/downloads/
- Npcap：需要管理员权限安装。https://npcap.com/#download

装好后，在程序菜单"工具 → 检测导入环境"里检查是否就绪。
导入步骤：先关掉游戏，在"导入"页点"开始扫描"，打开游戏进入大厅，再点"停止扫描"。
开着加速器抓不到数据时，可以用"工具 → 加速器网络诊断"查看原因。

存档和更新
----------
- 存档保存在"文档\FribbelsOptimizerSaves"里，不在程序文件夹中。
- 菜单"工具 → 检查更新"会检查维护版有没有新版本。
- 更新时，下载新的压缩包，用解压出来的新文件夹替换旧的即可，存档不受影响。
