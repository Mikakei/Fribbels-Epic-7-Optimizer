第七史诗 Fribbels 导入器 · 网络诊断工具
==========================================

用途
----
有些玩家开着加速器时，Fribbels 的自动导入抓不到数据。这个工具会记录登录游戏时，游戏数据走的是哪块网卡、哪个端口，用来判断加速器是怎么转发游戏流量的，以便修复导入器。

需要
----
- Python 3：安装时勾选 "Add Python to PATH"。https://www.python.org/downloads/
- Npcap：https://npcap.com/#download

在 Fribbels 自动导入用过的电脑上，这两样都已经装好了。

步骤
----
1. 完全关掉第七史诗。用模拟器的话，只关模拟器里的游戏，模拟器可以开着。
2. 双击 run-diagnose.cmd，会弹出一个黑色窗口。
3. 看到"现在打开加速器"的提示后，按你平时的方式打开加速器并开始加速，然后启动游戏，进入大厅。
4. 进入大厅后，回到黑色窗口按回车。
5. 报告保存在本文件夹的 reports 里，文件名是 importer-diagnose-日期-时间.txt。

把报告发回来时，请顺便说明：
- 用的是哪个加速器，什么模式（比如进程模式、路由模式、全局模式）
- 用的是 PC 客户端还是模拟器；如果是模拟器，是哪一个

隐私说明
--------
- 这个工具只在你的电脑上运行，不会上传任何东西。
- 报告里记录了这段时间内本机的网络连接：对方地址、端口、流量大小，以及每个连接前 3 个数据包各自的前 16 个字节。不包含账号密码，也不包含完整数据。
- 报告是普通文本文件，发送前可以用记事本打开看一遍。

其他
----
- 如果提示"没有可以抓包的网卡"，说明 Npcap 没装或没装好。
- 本工具附带 scapy 2.5.0（GPLv2 许可，见 LICENSE-scapy.txt）。
